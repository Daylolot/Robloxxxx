# КОНТУР — офисные аномалии Roblox

Публичный репозиторий проекта. Начни с [START_HERE.md](START_HERE.md). Порядок работы и шаблон записи для каждого коммита находятся в [CONTRIBUTING.md](CONTRIBUTING.md).

## Состояние проекта

- Рабочая карта: `maps/Kontur_Office_v17_No_Red_Lines.rbxl`.
- Карта проверки крови: `maps/Office_v17_BloodFlood_QA.rbxl`.
- Кровавая аномалия завершена по решению пользователя. Не перерабатывать без нового указания.
- Актуальный макет сотрудника — Blender v21. Подняты локти, исправлен резкий изгиб запястий, добавлены движущаяся отметка игрока на мониторе и связанный выключатель. В карте v17 остаётся прежняя игровая версия.
- Для сотрудника выбрана только связь ламп. Нижний ящик и новую тумбу не добавлять.

## Организация файлов

- `CHANGELOG.md` — изменения по этапам.
- `docs/DECISION_LOG.md` — обоснования решений, ограничения проверок и выявленные ошибки.
- `docs/ROADMAP.md` — следующие шаги.
- [Последний сеанс](sessions/2026-11-09-neutral-wrists.md) — поза рук, монитор и переключатель.
- [Макет v21 и обзор](models/ceiling-worker-v21/REVIEW.md) — сцена, сравнение, ролики и данные проверки.
- `sources/ceiling-worker-v21/` — скрипты пересборки позы, проверки и рендера.
- [Макет v20 и обзор](models/ceiling-worker-v20/REVIEW.md) — сцена, кадры, ролик со звуком и данные проверки.
- `sources/ceiling-worker-v20/` — скрипты анимации, проверки и рендера.
- [Макет v19 и обзор](models/ceiling-worker-v19/REVIEW.md) — файл Blender, кадры, ролик и данные проверки.
- `sources/ceiling-worker-v19/` — скрипты диагностики, правки позы и рендера.
- `models/ceiling-worker-v18/` — макет Blender, кадры, видео, HTML-просмотр и результаты проверок.
- `sources/ceiling-worker-v18/` — скрипты построения и проверки макета; это история работы, не одношаговый финальный сборщик.
- `maps/` — актуальные сохранённые карты.
- `docs/PROJECT_FILE_INDEX.json` — перечень проектных результатов и исходников в исходной рабочей папке, включая историю, ещё не перенесённую в этот пакет.

Для будущих рабочих этапов добавлять отдельную запись в `sessions/`: задача → фактические изменения → файлы → проверка → найденные ошибки → оставшаяся работа. Обновлять журнал решений и план. Загружать изменения на GitHub только когда доступен согласованный репозиторий; подтверждать успешную загрузку ссылкой и номером коммита.

Тяжёлые исторические Blender-кэши и версии должны храниться с сохранением относительных зависимостей. Не переносить один `.blend`, если ему нужна соседняя папка кэша. Установщики программ и зависимости не являются исходниками игры.

Анатомическая основа сотрудника: Blender Studio Human Base Meshes 1.4.1, CC0: https://www.blender.org/download/demo-files/ . Сцена и одежда доработаны локально. Это не полностью авторский скульпт с нуля.

Новые ресурсы Roblox не загружать и игру не публиковать без изменения текущих указаний пользователя. GitHub и публикация ресурсов Roblox — разные действия.
