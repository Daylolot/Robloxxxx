# KONTUR Perf Budget

> **Сейчас приоритет: максимум качества и красоты (указание пользователя 14.11.2026).** Этот скилл только **измеряет и записывает** цену. Светофор информационный: красный не запрещает улучшать визуал и добавлять контент. Ничего не урезать под телефоны и слабые ПК (детали, тени, свет, частицы, отражения). Допустимы только невидимые оптимизации кода. Режим для слабых устройств лежит в флаге `--perf` сборщика и не используется без указания. — цена предметов и аномалий

Зачем: телефон главный ограничитель проекта, а карта растёт версиями. Каждая аномалия и деталь должна иметь известную цену, иначе нагрузка прирастает незаметно и игра «не заходит» на слабых устройствах. Бюджеты и светофор лежат в `references/budgets.md` (прочитай его сначала: числа там стартовые, настоящие замеры их заменяют).

## Два уровня замера

**1. Статический (всегда, секунды).** Из корня репозитория:
```bash
python3 .claude/skills/kontur-perf-budget/scripts/static_scan.py sources --json > docs/evolution/scan_<версия>.json
python3 .claude/skills/kontur-perf-budget/scripts/static_scan.py sources --diff docs/evolution/scan_<прошлая>.json
```
Сканер по каждому `.luau`: объём (лимит клиентского скрипта ~300 тыс. символов), `--!strict`, циклы каждого кадра (`RenderStepped`, `Heartbeat`, `Stepped`, `while true`), `GetDescendants`, `Clone`, `Instance.new`, частицы, света, `EditableMesh`, `pcall`, Remote. С `--diff` показывает рост между версиями. Сначала папку `docs/evolution/` создай, если её нет.

**2. Живой (когда нужен вердикт по FPS).** Открой карту сам (`-task EditFile -localPlaceFile`, без вопросов). Запусти `scripts/studio_budget.luau` через мост:
```bash
../venv/bin/python ../studio_bridge.py <tool> --code .claude/skills/kontur-perf-budget/scripts/studio_budget.luau --mode Edit
```
(инструмент для выполнения Luau в Studio бери из списка, который отдаёт `StudioMCP`; образец вызова смотри в `sources/core-v37/studio_verify_core.py`). Скрипт считает детали, мэши, света (с тенями), эмиттеры, звуки, скрипты по комнатам и по моделям аномалий. Для кадра в Play включи аномалию и сними фон против аномалии по 5–10 секунд из одной точки камеры. Mac в Studio не равен iPhone: без замера на устройстве пиши «FPS на iPhone не измерен».

**Готовые харнессы (репозиторий KONTUR, `sources/evolution-v39/`).** `studio_measure_load.py` (счётчики теней, лучей, деталей до и после), `studio_measure_anomaly_cost.py` + `docs/evolution/cost_table.py` (цена каждой аномалии: дельта числа деталей, света, частиц, звуков, инстансов клиента к чистому раунду в той же точке), `studio_capture_view.py` (кадр из фиксированной точки для сравнения «до/после»). Они дают счётчики объектов, а не время кадра: окно Studio в автоматизации ограничено 15 к/с. Мост Studio иногда теряет окно после перезапуска: дождись `list_roblox_studios` и повтори.

## Что вернуть

1. Таблица «цена аномалии» по каждой аномалии: детали, света, частицы, циклы/кадр, класс (лёгкая/средняя/тяжёлая), дельта к прошлой версии, есть ли режим телефона.
2. Первыми проверь известные тяжёлые места (зеркало, принтер, растения, сотрудник на потолке), список в `references/budgets.md`.
3. **Светофор** по правилам из `references/budgets.md`. Без замера на телефоне максимум жёлтый.
4. Что вышло за бюджет, что дёшево и можно улучшать, что **не измерено**.

## Выход

```
## Цена (рендер и CPU)
Светофор: ...
| Аномалия / предмет | Детали | Света | Частицы | Циклы/кадр | Класс | Δ к прошлой | Режим телефона |
Выводы: ...
Не измерено: ...
Передать: kontur-visual-direction (светофор и дорогие/дешёвые места)
```

Решения «что улучшать» не принимай здесь: отдай светофор в `kontur-visual-direction`. Исправления нагрузки (оптимизации) оформляй как задачи в бэклог, не меняй игру в этом скилле.
