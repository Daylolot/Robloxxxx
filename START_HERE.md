# Начни здесь

КОНТУР — карта Roblox с офисными аномалиями. Игроки осматривают офис и отвечают у стойки. Первый уровень чистый, второй содержит аномалию, далее вероятность составляет 72%.

1. Прочитай [состояние проекта](README.md), [историю проекта по сообщениям](docs/PROJECT_HISTORY.md) и [журнал изменений](CHANGELOG.md).
2. Найди принятые решения в [журнале обоснований](docs/DECISION_LOG.md) и текущий порядок задач в [плане](docs/ROADMAP.md).
3. Для принтера открой [тестовую карту v35](maps/Kontur_Office_v35_QA.rbxl). Для зеркала открой [карту v26](maps/Kontur_Office_v26_Mirror.rbxl) или [тестовую карту v26](maps/Kontur_Office_v26_Mirror_QA.rbxl). Для сотрудника открой [карту v24](maps/Kontur_Office_v24_Ceiling_Worker.rbxl) в Roblox Studio. Для показа сотрудника на втором уровне есть [тестовая карта v24](maps/Kontur_Office_v24_Ceiling_Worker_QA.rbxl). Для проверки крови есть [карта QA](maps/Office_v17_BloodFlood_QA.rbxl).
4. Для осмотра нового сотрудника скачай [сцену Blender v24](models/ceiling-worker-v24/Ceiling_Office_Character_Study_v24.blend). [Обзор](models/ceiling-worker-v24/REVIEW.md) содержит сравнение позы и проверку в игре.
5. Перед работой прочитай [правила нового коммита](CONTRIBUTING.md).

## Текущая точка

Актуальные копии — [игровая карта v35](maps/Kontur_Office_v35.rbxl) и [карта QA v35](maps/Kontur_Office_v35_QA.rbxl). [Обзор](models/anomalies-v35/REVIEW.md) содержит Blender, кадры, проверки и ссылки на исходники. Для просмотра новых раундов используй `GreenVent` или `WhisperDoor` по [инструкции QA](sources/anomalies-v35/README.md).

В Blender v28 собраны предупреждение, отсчёт и 42 отдельных полёта. [Сцена, ролик и отчёт](models/printer-v28/REVIEW.md).

В v30 принтер выдаёт предупреждение тремя протяжками и запускает пять секунд отсчёта после чтения. 60 листов отрываются от стопок по очереди. После взлёта часть бумаги спускается в проходы, часть летит на уровне глаз и выше. [Обзор v30](models/printer-v30/REVIEW.md).

В v26 левое зеркало женского санузла показывает фигуру под потолком. [Обзор v26](models/mirror-v26/REVIEW.md).

Кровь согласована. В Studio карта v24 показывает новую посадку сотрудника и исправленные кисти. Подробности и кадры в [обзоре v24](models/ceiling-worker-v24/REVIEW.md).

Не публикуй игру и новые ресурсы в Roblox без нового указания. После работы сохраняй нужные файлы и закрывай лишние окна Studio. Если самостоятельный просмотр не запрошен, закрывай Studio полностью.

[Индекс исходной рабочей папки](docs/PROJECT_FILE_INDEX.json) показывает, какие старые версии и кэши есть на Mac. Запись в индексе не гарантирует присутствие файла в репозитории.
