# Начни здесь

КОНТУР — карта Roblox с офисными аномалиями. Игроки осматривают офис и отвечают у стойки. Первый уровень чистый, второй содержит аномалию, далее вероятность составляет 72%.

1. Прочитай [состояние проекта](README.md), затем [журнал изменений](CHANGELOG.md) и последнюю запись в [sessions](sessions/).
2. Найди принятые решения в [журнале обоснований](docs/DECISION_LOG.md) и текущий порядок задач в [плане](docs/ROADMAP.md).
3. Для игры открой [карту v17](maps/Kontur_Office_v17_No_Red_Lines.rbxl) в Roblox Studio. Для проверки крови есть [карта QA](maps/Office_v17_BloodFlood_QA.rbxl).
4. Для осмотра нового сотрудника скачай [сцену Blender](models/ceiling-worker-v18/Ceiling_Office_Character_Study_v18.blend). Для локальной галереи скачай целиком её папку, чтобы изображения и ролик лежали рядом с HTML.
5. Перед работой прочитай [правила нового коммита](CONTRIBUTING.md).

## Текущая точка

Кровь согласована. Сотрудник v18 остаётся художественным макетом, в карте v17 стоит прежняя игровая версия. Пользователь заметил перевёрнутые кисти. При возобновлении первым делом проверить стороны кистей, большие пальцы, предплечья, плечи и локти в движении. Связать только лампы, нижняя тумба не требуется. Разработка сотрудника приостановлена пользователем.

Не публикуй игру и новые ресурсы в Roblox без нового указания. После работы сохраняй нужные файлы и закрывай лишние окна Studio. Если самостоятельный просмотр не запрошен, закрывай Studio полностью.

[Индекс исходной рабочей папки](docs/PROJECT_FILE_INDEX.json) показывает, какие старые версии и кэши есть на Mac. Запись в индексе не гарантирует присутствие файла в репозитории.
