# Инструменты проверки жидкости

Скрипты, которыми проверялся фронт волны (v39F). Запускать из этой папки, `python` из venv (`../venv/bin/python`) с Pillow; `studio_bridge.py` лежит в `Robloxxxx_work` (путь прописан в `sb.py`). Папка `front/` для кадров создаётся рядом.

- `edit_front.py <тег> <часть имени файла карты> [варианты]`: строит поверхность жидкости прямо в Edit-режиме Studio (без Play и ожидания раунда), замораживает момент волны, снимает 12 кадров (коридор, комната) и меряет цену `Surface:Update`. Варианты: `before` (модули v38 из `original/`), `after` (текущие файлы слоя), `A`/`B`/`r45`/`r60` (подстановка констант).
- `play_front.py <тег> <часть имени файла карты>`: живой раунд в Play, кадры по ходу потопа и время смертельного контакта игрока, стоящего в коридоре.
- Studio открывай своим процессом (`-task EditFile -localPlaceFile`), закрывай только свой PID. Параллельные скрипты других сессий берут первую студию из списка: работай, когда чужой Studio закрыт.
