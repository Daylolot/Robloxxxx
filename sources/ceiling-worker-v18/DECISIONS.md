# Сотрудник на потолке — рабочая переработка v18

Основа карты: Kontur_Office_v17_No_Red_Lines.rbxl. Кровь завершена, не менять.
Пользователь выбрал предложенную комбинацию: настоящее рабочее место на потолке, участок ковролина в потолочных плитах и ощущение второго офиса.

Согласовано 8 ноября:
- Мужчина около 33 лет.
- Спокойно прекращает работу и медленно следит взглядом.
- Не убивает, только пугает.
- Требуется реалистичная внешность и тщательная работа в Blender.
- По просьбе пользователя отправлены две дополнительные серии по десять вопросов, их ответы зафиксированы ниже. Позднее выбран вариант «только связь ламп», без нижнего ящика.

Ответы на последующие вопросы:
- Обычное телосложение, слегка сутулится.
- Белая рубашка, ослабленный галстук, тёмные брюки.
- Аккуратный пробор, чисто выбрит.
- Едва заметная тревожная улыбка.
- Маленький кабинет, перегородка, полка.
- Полный прежний набор занятий: печатает, мышь, бумаги, кофе.
- Реакция через 1,5 с взгляда.
- Несколько секунд смотрит вслед, затем возвращается к работе.
- Без голоса: дыхание, клавиатура, бумага, кресло.
- Приподнятые потолочные плиты, тёмная щель, толщина перекрытия.
- Тусклый желтоватый свет, редкое мерцание.
- Сначала игрок замечает пустой нижний стол, потом верхний кабинет.
- Нижний стол трактуется как пустая столешница. Окончательный выбор: **связывать только лампы, без нижнего ящика и новой тумбы**. Компьютер под столом сохраняется.
- Верхний монитор показывает план офиса с игроками.
- Вещи, вылетевшие за границу верхнего кабинета, падают на настоящий пол. Без урона.
- Повторный вход ничего дополнительно не меняет.
- Папки, календарь, стикеры, небольшое растение.
- Кабинет исчезает во время штатного перехода уровня, потолок восстанавливается.

Текущая стадия: первый подробный художественный макет Blender. Нативная v17 НЕ изменена. Скрипты игры пока не установлены и не тестировались.
